# 象数演易 - 四区块教学应用布局规范

## 1. 概述

本规范定义了象数演易平台教学应用的布局结构、设计风格和交互要求，确保所有生成的教学应用具有一致的视觉体验和良好的用户体验。

## 2. 四区块架构

```
┌─────────────────────────────────────────────────────────┐
│                    1. 标题区                             │
│  (顶部固定，全屏宽度，包含标题、标签、难度)               │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│  桌面端: 2. 画布区 (50%)   │   3. 步骤区 (50%)         │
│  移动端: 垂直排列，各占100%宽度                          │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│                    4. 控制区                             │
│  (跨列底部，包含练习控件、反馈提示、操作按钮)            │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│         附加区域: 题目内容、知识点、常见错误            │
└─────────────────────────────────────────────────────────┘
```

## 3. 区块详细说明

### 3.1 标题区 (Header)
- **位置**: 页面最顶部，粘性定位 (`sticky top-0`)
- **样式**: 
  - 渐变色背景: `from-xsyy-blue to-blue-800`
  - 卡片样式: `py-6 shadow-xl`
- **内容**:
  - 主标题: `text-2xl md:text-3xl font-bold`
  - 标签行: 胶囊样式 (`rounded-full`)
    - 主标签: `xsyy-cyan` 色系
    - 子标签: 白色半透明
    - 难度标签: 绿色系

### 3.2 画布区 (Canvas Area)
- **位置**: 桌面端左侧，移动端上方
- **样式**:
  - 圆角白色卡片: `rounded-2xl shadow-xl`
  - 标题栏: 渐变蓝色，带图标
  - 内容区: 渐变米白背景 `from-xsyy-cream to-white`
  - 最小高度: `min-h-[400px]`
- **功能**: 动态可视化、几何图形、函数曲线等

### 3.3 步骤区 (Steps Area)
- **位置**: 桌面端右侧，移动端画布区下方
- **样式**:
  - 圆角白色卡片: `rounded-2xl shadow-xl`
  - 标题栏: 渐变蓝色，带展开/收起按钮
  - 步骤列表: 
    - 虚线分隔: `divide-y divide-dashed divide-gray-300`
    - 每步: `p-6 border-l-4`
    - 当前步骤高亮: `border-xsyy-blue`
    - 未完成步骤: `border-gray-300 opacity-70`
- **交互**: 点击步骤高亮已完成的部分

### 3.4 控制区 (Controls Area)
- **位置**: 页面底部，跨列
- **样式**:
  - 圆角白色卡片: `rounded-2xl shadow-xl`
  - 标题栏: 渐变金色 (`from-xsyy-gold to-yellow-600`)
- **功能**:
  - 练习控件: 滑块、选择、输入框
  - 反馈提示: 左侧边框高亮
  - 操作按钮: 提交、提示、重置

## 4. 视觉设计规范

### 4.1 颜色系统
```
xsyy-blue:   #1a365d  (主色)
xsyy-cream:  #f7f3e9  (背景色)
xsyy-gold:   #d4a574  (强调色)
xsyy-cyan:   #a3d9ff  (辅助色)
```

### 4.2 间距规范
- 区块外边距: `mb-8`
- 卡片内边距: `p-6`
- 标题栏内边距: `px-6 py-4`
- 区块间距: `gap-8` (网格布局)

### 4.3 响应式断点
- 移动端 (< 1024px): 全列 `grid-cols-1`
- 桌面端 (≥ 1024px): 双列 `lg:grid-cols-2`

### 4.4 字体
- 主字体: `Noto Serif SC` (思源宋体)
- 标题: 加粗
- 正文: 常规字重

## 5. 交互规范

### 5.1 步骤交互
- 点击任一步骤，高亮该步骤及之前的所有步骤
- 更新步骤号圆圈颜色
- 更新步骤标题颜色

### 5.2 控件反馈
- 任何交互在 4 秒内显示反馈提示
- 成功: 绿色边框
- 信息: 蓝色边框
- 提示: 随机显示学习建议

### 5.3 重置功能
- 重置步骤到第一步
- 清空所有输入/选择
- 重置滑块到默认值

## 6. AI 生成 Prompt 要点

### 6.1 `generate_teaching_steps` (DeepSeek)
```
请设计结构化教学方案，返回JSON格式：
- knowledge_points: 3-5个核心知识点
- steps: 2-4个步骤，包含title、description、interaction_hint
- common_mistakes: 2-3个常见错误
- practice_suggestion: type(slider|choice|input) + question + options
```

### 6.2 `generate_application` (Gemini)
```
请生成HTML单文件：
1. 使用 Tailwind CSS CDN
2. 新中式风格 (#1a365d, #f7f3e9)
3. 四区块布局:
   - 标题区: 顶部
   - 画布区+步骤区: 桌面端并排，移动端垂直
   - 控制区: 底部跨列
4. 每个区块圆角白色卡片，渐变标题栏
5. 支持步骤点击高亮
6. 响应式
```
