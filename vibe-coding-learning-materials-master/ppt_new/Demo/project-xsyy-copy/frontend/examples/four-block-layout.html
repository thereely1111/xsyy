二次函数 y = ax² + bx + c

📝 解题步骤

1

识别二次项系数

首先确定二次函数的标准形式 y = ax² + bx + c，其中 a 是二次项系数，决定开口方向。

示例：y = 2x² + 3x - 1 中，a = 2

2

计算顶点坐标

使用公式计算顶点位置：x = -b/(2a)，然后代入求 y 值。

顶点 x = -3/(2×2) = -0.75

3

绘制图像

根据顶点和系数，绘制抛物线图像。
