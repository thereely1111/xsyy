# 产品需求文档

> **项目名称**：象数演易（XSYY）- AI驱动的数学教学应用生成平台  
> **版本**：V1.0  
> **日期**：2026-05-28  
> **文档状态**：初稿

---

## 1. 产品概述

### 1.1 产品定位
象数演易（XSYY）是一款基于AI技术的数学教学应用生成平台，旨在将复杂的数学题目通过AI分析后，自动生成包含动画演示、分步讲解和交互练习的自包含HTML教学应用。

### 1.2 核心价值
| 价值点 | 描述 |
|--------|------|
| 降本增效 | AI自动生成教学应用，减少教师备课时间 |
| 个性化学习 | 基于语义推荐，提供针对性学习内容 |
| 轻量化交付 | 生成单HTML文件，无外部依赖，易于分享传播 |

---

## 2. 用户角色

| 角色 | 描述 | 权限范围 |
|------|------|----------|
| **学生** | 观看学习应用、收藏内容、参与练习 | 浏览、收藏、练习、评论、点赞 |
| **教师** | 创建教学应用、管理个人作品 | 学生权限 + 创建应用、管理作品 |
| **内容创作者** | 专业生产优质教学内容 | 教师权限 + 内容变现、收益管理 |
| **管理员** | 系统运营与内容审核 | 全系统管理、审核、配置 |

## 3. 功能模块

### 3.1 智能题目分析

#### 3.1.1 题目输入
| 输入方式 | 说明 |
|----------|------|
| 文本输入 | 支持数学公式LaTeX语法、手写体OCR识别 |
| 图片上传 | 支持JPG/PNG，最大5MB，自动OCR提取 |

#### 3.1.2 AI分析输出
| 输出字段 | 类型 | 说明 |
|----------|------|------|
| `title` | string | 自动生成的题目标题 |
| `primary_tag` | string | 主标签（如：代数、几何、概率） |
| `secondary_tags` | array[string] | 子标签（如：一次函数、三角形） |
| `difficulty` | enum | 简单/中等/困难/竞赛级 |
| `knowledge_points` | array[object] | 知识点清单 |
| `estimated_time` | int | 预计完成时间（分钟） |

#### 3.1.3 业务规则
- 题目内容进行敏感词过滤
- 相同题目24小时内不重复分析（缓存）
- 分析超时时间为30秒，超时返回错误

### 3.2 交互式教学应用生成

#### 3.2.1 生成流程
```mermaid
flowchart TD
    A[输入题目] --> B[AI分析题目结构]
    B --> C[生成讲解文案]
    C --> D[设计动画演示]
    D --> E[创建交互练习]
    E --> F[打包HTML]
    F --> G[存储与发布]
```

#### 3.2.2 HTML应用结构
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <style>/* 内嵌Tailwind + 自定义样式 */</style>
</head>
<body>
    <!-- 标题区域 -->
    <!-- 动画演示区 -->
    <!-- 分步讲解区 -->
    <!-- 交互练习区 -->
    <!-- 答案与解析区 -->
</body>
</html>
```

#### 3.2.3 功能特性
| 模块 | 功能点 | 描述 |
|------|--------|------|
| **动画演示** | 几何变换、函数图像、步骤还原 | 支持播放/暂停/重置 |
| **分步讲解** | 逐步展开、关键步骤高亮 | 支持展开/折叠 |
| **交互练习** | 选择题、填空题、解答题 | 即时反馈对错 |
| **响应式** | 移动端适配 | 断点：640px/768px/1024px |

## 7. 安全与合规

### 7.1 安全措施
| 措施 | 实现 |
|------|------|
| 密码存储 | bcrypt，salt轮数12 |
| SQL注入 | ORM参数化查询 |
| XSS防护 | 输入过滤、输出转义 |
| CSRF防护 | Token验证 |
| 敏感操作 | 二次验证 |
| API限流 | 每IP 100次/分钟 |

### 7.2 内容安全
- 用户上传图片进行AI审核
- 题目内容敏感词过滤
- 评论内容先发后审

## 8. 错误处理策略

### 8.1 错误码定义
| 错误码 | HTTP状态码 | 说明 |
|--------|------------|------|
| `AUTH_001` | 401 | 无效Token |
| `AUTH_002` | 401 | Token过期 |
| `AUTH_003` | 403 | 权限不足 |
| `USER_001` | 409 | 用户名已存在 |
| `USER_002` | 404 | 用户不存在 |
| `APP_001` | 404 | 应用不存在 |
| `APP_002` | 403 | 无权访问该应用 |
| `TASK_001` | 404 | 任务不存在 |
| `TASK_002` | 500 | AI服务超时 |
| `VALIDATION_001` | 422 | 参数校验失败 |
| `SYSTEM_001` | 500 | 系统内部错误 |

### 8.2 错误响应格式
```json
{
    "error": {
        "code": "AUTH_001",
        "message": "无效的访问令牌",
        "details": {}
    }
}
```

## 9. 性能优化策略

### 9.1 缓存策略
| 缓存层级 | 内容 | 过期时间 |
|----------|------|----------|
| 浏览器 | 静态资源 | 1年 |
| CDN | 公共资源 | 1天 |
| Redis | 会话、热门数据 | 5分钟-1小时 |
| 本地内存 | 热点数据 | 30秒 |

### 9.2 异步处理
| 场景 | 实现 |
|------|------|
| AI分析 | BackgroundTasks，5分钟超时 |
| HTML生成 | Celery任务队列 |
| 发送通知 | 异步消息队列 |
| 统计数据 | 定时批处理 |

### 9.3 数据库优化
- 读写分离
- 分表（按用户ID分表）
- 索引优化（联合索引）
- 查询缓存
