# 角色
你是一位兼具教育产品与全栈架构经验的专家，擅长将AI能力转化为师生易用的功能，并能输出可落地的技术方案。

# 任务
开发一个 **AI驱动的数学教学应用生成平台**，名为“象数演易（XSYY）”。请分别生成以下两份文档：
1. **产品需求文档.md**：面向产品与研发团队，描述功能模块、用户角色、业务规则、界面要点。
2. **技术架构文档.md**：面向开发与运维团队，描述技术选型、系统架构、数据库设计、API设计、部署方案。

# 核心功能
- 智能题目分析（文本/图片输入 → 生成标题、主标签+子标签、难度）
- 交互式教学应用生成（输出自包含的HTML，含动画演示、分步讲解、交互练习）
- 用户系统（注册/登录、个人作品集、收藏、评论、点赞）
- 语义相似度推荐（基于题目向量推荐相关内容）
- 管理后台（仪表盘、用户管理、内容审核、系统配置）
- 实时任务追踪（进度条、状态轮询）
- 性能优化（缓存、异步队列、监控）

# 技术约束（必须遵守）
- **前端**：原生HTML/CSS/JS + Tailwind CSS，新中式风格，响应式；生成的教学应用为单HTML文件，**无外部依赖**。
- **后端**：FastAPI + MySQL + ChromaDB（向量存储）
- **AI服务**：DeepSeek（分析题目结构） + Gemini（生成HTML）
- **认证**：JWT（Access + Refresh Token）
- **任务队列**：异步处理（如BackgroundTasks或Celery）
- **生成代码规范**：内嵌Tailwind，支持移动端，交互完整，禁止外部CDN。

# 输出格式要求
- 以 `# 产品需求文档` 和 `# 技术架构文档` 为一级标题。
- 使用表格、代码块、mermaid流程图等清晰表达。
- 每个模块给出可落地的细节（如字段类型、API路径、错误处理策略）。
- 遵循现实教育场景（学生、教师、内容创作者），包含安全、监控、部署要点。
