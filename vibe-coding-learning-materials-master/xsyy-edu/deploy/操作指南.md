# XSYY 项目部署操作指南

## 📋 部署前准备清单

### 1. 服务器信息
- [ ] 已获取腾讯云服务器 IP 地址
- [ ] 已获取服务器 root 或 sudo 权限
- [ ] 已确认操作系统为 OpenCloudOS

### 2. 数据库信息
- [ ] 已创建腾讯云 TencentDB MySQL 实例
- [ ] 已获取数据库连接信息：
  - 主机地址（如：cdb-xxxxx.sql.tencentcdb.com）
  - 端口（通常为 3306）
  - 数据库名（建议：xsyy）
  - 用户名
  - 密码

### 3. 项目文件
- [ ] 已准备好项目代码（可通过 git clone 或 scp 上传）

---

## 🚀 快速部署步骤

### 步骤 1：连接服务器

```bash
ssh root@your_server_ip
```

### 步骤 2：安装系统依赖

```bash
# 更新系统
sudo yum update -y

# 安装 Python 3.9 和开发工具
sudo yum install -y python39 python39-pip python39-devel gcc

# 安装 MySQL 客户端库
sudo yum install -y mysql-devel

# 安装 Nginx
sudo yum install -y nginx

# 安装其他必要工具
sudo yum install -y git
```

### 步骤 3：上传项目代码

**方式一：使用 git（推荐）**
```bash
# 创建项目目录
sudo mkdir -p /opt/xsyy
sudo chown $USER:$USER /opt/xsyy

# 克隆代码
cd /opt/xsyy
git clone <your-repo-url> .
```

**方式二：使用 scp（从本地）**
```bash
# 在本地电脑执行
scp -r D:\nick\大模型应用工程师\XSYY root@your_server_ip:/opt/xsyy
```

### 步骤 4：配置 Python 虚拟环境

```bash
cd /opt/xsyy/backend

# 创建虚拟环境
python3.9 -m venv .venv

# 激活虚拟环境
source .venv/bin/activate

# 升级 pip
pip install --upgrade pip

# 安装依赖
pip install -r requirements.txt
```

### 步骤 5：配置环境变量

```bash
cd /opt/xsyy/backend

# 复制环境变量模板
cp env.example .env

# 编辑环境变量文件
nano .env
```

在 `.env` 文件中填入以下内容：

```env
# 数据库连接（替换为你的实际数据库信息）
DATABASE_URL=mysql+pymysql://用户名:密码@主机地址:3306/xsyy?charset=utf8mb4

# JWT 密钥（必须修改为随机字符串）
JWT_SECRET=your-very-secure-secret-key-change-this-in-production

# API 密钥
DEEPSEEK_API_KEY=your_deepseek_api_key
ZENMUX_API_KEY=your_zenmux_api_key

# 可选配置
DEEPSEEK_MODEL_NAME=deepseek-chat
# ZENMUX 图片生成模型（预览图）
ZENMUX_IMAGE_MODEL=google/gemini-3.1-flash-lite-image
# ZENMUX HTML 生成模型（交互式教学页面）
ZENMUX_HTML_MODEL=google/gemini-3.1-flash-lite
# ZENMUX AI 助教回答模型
ZENMUX_RESPONSE_MODEL=google/gemini-3.1-flash-lite
```

**重要提示：**
- `DATABASE_URL` 格式：`mysql+pymysql://用户名:密码@主机:端口/数据库名?charset=utf8mb4`
- `JWT_SECRET` 必须修改为强随机字符串（可使用 `openssl rand -hex 32` 生成）

### 步骤 6：初始化数据库

#### 6.1 在 MySQL 中创建数据库（如果还没有）

连接到你的 MySQL 数据库（可以使用腾讯云控制台的数据库管理工具，或使用 MySQL 客户端）：

```sql
CREATE DATABASE IF NOT EXISTS xsyy CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

#### 6.2 初始化数据库表结构

```bash
cd /opt/xsyy/backend
source .venv/bin/activate

# 使用初始化脚本（推荐）
python init_database.py

# 或者使用 SQL 脚本（如果上述方式失败）
# mysql -h your_host -u your_user -p xsyy < database/schema.sql
```

#### 6.3 迁移现有数据（如果有 JSON 文件数据）

```bash
cd /opt/xsyy/backend
source .venv/bin/activate
python database/migrate.py
```

### 步骤 7：配置 systemd 服务

```bash
# 复制服务文件
sudo cp /opt/xsyy/deploy/xsyy-backend.service /etc/systemd/system/

# 检查并修改服务文件中的路径（如果需要）
sudo nano /etc/systemd/system/xsyy-backend.service

# 重新加载 systemd
sudo systemctl daemon-reload

# 启动服务
sudo systemctl start xsyy-backend

# 设置开机自启
sudo systemctl enable xsyy-backend

# 查看服务状态
sudo systemctl status xsyy-backend
```

**如果服务启动失败，查看日志：**
```bash
sudo journalctl -u xsyy-backend -n 50
```

### 步骤 8：配置 Nginx

```bash
# 复制 Nginx 配置文件
sudo cp /opt/xsyy/deploy/nginx.conf /etc/nginx/sites-available/xsyy

# 编辑配置文件，修改域名或 IP
sudo nano /etc/nginx/sites-available/xsyy
```

**修改 `server_name` 行：**
```nginx
server_name your_domain.com;  # 或 your_server_ip
```

```bash
# 创建软链接
sudo ln -s /etc/nginx/sites-available/xsyy /etc/nginx/sites-enabled/

# 测试 Nginx 配置
sudo nginx -t

# 如果测试通过，启动 Nginx
sudo systemctl start nginx
sudo systemctl enable nginx
```

### 步骤 9：配置防火墙

```bash
# 开放 HTTP 端口
sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --reload

# 如果使用 HTTPS，还需要开放 HTTPS
sudo firewall-cmd --permanent --add-service=https
sudo firewall-cmd --reload
```

### 步骤 10：设置文件权限

```bash
# 确保 storage 目录有写权限
sudo chown -R www-data:www-data /opt/xsyy/storage
sudo chmod -R 755 /opt/xsyy/storage

# 确保 web 目录有读权限
sudo chown -R www-data:www-data /opt/xsyy/web
sudo chmod -R 755 /opt/xsyy/web

# 确保 backend 目录有执行权限
sudo chown -R www-data:www-data /opt/xsyy/backend
sudo chmod -R 755 /opt/xsyy/backend
```

## 🐛 常见问题排查

### 问题 1：后端服务无法启动

**检查步骤：**
1. 查看服务状态：`sudo systemctl status xsyy-backend`
2. 查看详细日志：`sudo journalctl -u xsyy-backend -n 100`
3. 检查环境变量：确认 `.env` 文件存在且配置正确
4. 检查数据库连接：确认 `DATABASE_URL` 正确且数据库可访问
5. 检查 Python 环境：确认虚拟环境已激活且依赖已安装

**常见错误：**
- `ModuleNotFoundError`：依赖未安装，运行 `pip install -r requirements.txt`
- 数据库连接失败：检查 `DATABASE_URL` 和数据库网络连接
- 端口被占用：检查 8000 端口是否被其他程序占用

### 问题 2：Nginx 502 Bad Gateway

**检查步骤：**
1. 确认后端服务正在运行：`sudo systemctl status xsyy-backend`
2. 确认后端服务监听 8000 端口：`sudo netstat -tlnp | grep 8000`
3. 查看 Nginx 错误日志：`sudo tail -f /var/log/nginx/xsyy_error.log`
4. 测试后端 API：`curl http://localhost:8000/api/health`

### 问题 3：数据库连接失败

**检查步骤：**
1. 确认数据库连接信息正确（主机、端口、用户名、密码、数据库名）
2. 测试数据库连接：
   ```bash
   mysql -h your_host -u your_user -p xsyy
   ```
3. 检查防火墙规则（如果数据库在远程服务器）
4. 确认数据库用户有足够权限

### 问题 4：文件权限问题

**解决方法：**
```bash
# 重新设置文件权限
sudo chown -R www-data:www-data /opt/xsyy
sudo chmod -R 755 /opt/xsyy
sudo chmod -R 775 /opt/xsyy/storage  # storage 需要写权限
```
