## 🔄 分支工作流

```
                    main (生产环境)
                      ↑
                      │ 合并
                      │
            ┌─────────┴─────────┐
            │                   │
      develop (开发环境)    hotfix (紧急修复)
            ↑                   ↑
            │ 合并              │ 从 main 创建
            │                   │
      feature/新功能1      feature/新功能2
            ↑                   ↑
            │ 开发               │ 开发
            │                   │
        本地开发              本地开发
```

---

## 📋 详细步骤说明

### 场景 A: 开发新功能

```
1. 本地开发
   └─> 创建功能分支: git checkout -b feature/新功能
   └─> 修改代码
   └─> 提交: git commit -m "添加新功能"

2. 推送到远程
   └─> git push origin feature/新功能

3. 合并到 develop
   └─> 通过 Pull Request 或命令行合并
   └─> 触发自动部署到开发服务器

4. 测试
   └─> 在开发服务器上测试功能
   └─> 确认没问题

5. 合并到 main
   └─> git checkout main
   └─> git merge develop
   └─> git push origin main
   └─> 触发自动部署到生产服务器

6. 完成
   └─> 用户可以使用新功能
```

### 场景 B: 修复紧急bug

```
1. 发现问题
   └─> 用户报告bug

2. 创建 hotfix 分支
   └─> git checkout main
   └─> git checkout -b hotfix/修复bug

3. 修复并部署
   └─> 修复代码
   └─> git commit -m "修复bug"
   └─> git push origin hotfix/修复bug
   └─> git checkout main
   └─> git merge hotfix/修复bug
   └─> git push origin main
   └─> 自动部署到生产服务器

4. 完成
   └─> 问题解决
```

## 🛠️ 部署脚本执行流程

```
开始部署
  │
  ├─> 1. 备份当前版本
  │     └─> 备份代码到 /opt/xsyy/backups/
  │     └─> 备份数据库（生产环境）
  │
  ├─> 2. 拉取最新代码
  │     └─> git fetch
  │     └─> git checkout 指定分支
  │     └─> git pull
  │
  ├─> 3. 更新依赖
  │     └─> 激活虚拟环境
  │     └─> pip install -r requirements.txt
  │
  ├─> 4. 数据库迁移
  │     └─> 初始化数据库（如果需要）
  │     └─> 运行迁移脚本
  │
  ├─> 5. 重启服务
  │     └─> 停止旧服务
  │     └─> 启动新服务
  │
  ├─> 6. 健康检查
  │     └─> 检查服务是否正常
  │     └─> 如果失败，自动回滚
  │
  └─> 完成
        └─> 记录部署信息
```

---

## 🔄 回滚流程

```
部署失败
  │
  ├─> 检测到服务异常
  │
  ├─> 自动回滚
  │     ├─> 停止服务
  │     ├─> 恢复代码（从备份）
  │     ├─> 恢复数据库（如果需要）
  │     └─> 重启服务
  │
  └─> 回滚完成
        └─> 服务恢复到上一个版本
```

## 💡 记忆口诀

**开发流程**：
```
改代码 → 提交 → 推送 → 自动部署 → 完成
```

**紧急修复**：
```
发现问题 → 创建 hotfix → 修复 → 合并 → 自动部署 → 解决
```

**回滚**：
```
部署失败 → 自动回滚 → 恢复 → 完成
```
