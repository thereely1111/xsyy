# 快速开始指南

## 🚀 第一次使用（5分钟上手）

### 前置条件

1. **服务器已安装 Git**
   ```bash
   git --version
   ```

2. **服务器已安装 Python 3.9+**
   ```bash
   python3 --version
   ```

3. **服务器已配置 SSH 密钥**（用于 GitHub Actions）

---

## 📝 第一次部署（手动方式）

### 步骤 1: 在服务器上准备项目

```bash
# 1. 创建项目目录
sudo mkdir -p /opt/xsyy
sudo chown $USER:$USER /opt/xsyy

# 2. 克隆代码（或上传代码）
cd /opt/xsyy
git clone <你的Git仓库地址> .

# 3. 给脚本添加执行权限
chmod +x deploy/*.sh
```

### 步骤 2: 配置环境变量

```bash
cd /opt/xsyy/backend
cp .env.example .env
nano .env  # 编辑环境变量
```

### 步骤 3: 首次部署

```bash
# 开发环境
cd /opt/xsyy
./deploy/deploy-dev.sh

# 或生产环境
./deploy/deploy-prod.sh
```

---

## 🔄 日常更新代码（3步完成）

### 方式一：手动更新（最简单）

**在服务器上执行：**

```bash
cd /opt/xsyy

# 开发环境
./deploy/deploy-dev.sh

# 生产环境
./deploy/deploy-prod.sh
```

### 方式二：自动更新（推荐）

**在本地电脑上：**

```bash
# 1. 修改代码
# 2. 提交代码
git add .
git commit -m "添加新功能"
git push origin develop  # 开发环境
# 或
git push origin main     # 生产环境
```

**系统自动：**
- GitHub Actions 检测到代码更新
- 自动执行部署脚本
- 2-5 分钟后，服务器自动更新

## 📋 常用命令速查

### 查看部署状态

```bash
# 查看服务状态
sudo systemctl status xsyy-backend

# 查看日志
sudo journalctl -u xsyy-backend -f

# 查看部署信息
cat /opt/xsyy/.deploy_info
```

### 回滚到上一个版本

```bash
cd /opt/xsyy
./deploy/rollback.sh
```

### 查看版本信息

```bash
cd /opt/xsyy
./deploy/version.sh
cat .version
```

## ⚠️ 重要提醒

1. **生产环境部署前一定要测试**
   - 先在开发环境测试
   - 确认没问题再部署到生产

2. **部署前备份**
   - 脚本会自动备份
   - 备份位置：`/opt/xsyy/backups/`

3. **遇到问题立即回滚**
   ```bash
   ./deploy/rollback.sh
   ```

---

## 🆘 遇到问题？

### 问题 1: 脚本没有执行权限

```bash
chmod +x deploy/*.sh
```

### 问题 2: 服务启动失败

```bash
# 查看日志
tail -f /tmp/xsyy-backend.log
# 或
sudo journalctl -u xsyy-backend -f
```

### 问题 3: 数据库连接失败

```bash
# 检查环境变量
cat backend/.env | grep DATABASE_URL

# 测试连接
python backend/check_db.py
```

### 问题 4: 需要回滚

```bash
# 查看可用备份
ls -lt /opt/xsyy/backups/

# 回滚到指定备份
./deploy/rollback.sh 20241219_143022
```
