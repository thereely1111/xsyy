# 每日调用次数限制功能说明

## 功能概述

为每个用户设置每日最大调用次数限制，防止滥用。该限制可以动态修改。

## 数据库字段

在 `users` 表中新增了以下字段：

- `daily_max_calls` (INT, 默认值: 6): 每日最大调用次数（可修改）
- `daily_calls_count` (INT, 默认值: 0): 当天已调用次数
- `last_call_date` (DATETIME, 可为空): 最后调用日期（用于重置计数）

## 数据库迁移

执行以下命令进行数据库迁移：

```bash
# Windows
backend\database\add_daily_calls_fields.bat

# 或直接运行 Python 脚本
python backend\database\add_daily_calls_fields.py
```

## API 接口

### 1. 创建任务时自动检查

`POST /api/tasks` 接口会自动检查用户的调用次数：

- 如果用户已登录，会检查并增加调用次数
- 如果超过限制，返回 429 错误：`今日调用次数已达上限（X次），请明天再试`
- 如果未登录，不进行限制（匿名用户）

### 2. 获取用户信息（包含调用次数）

`GET /api/auth/me` 接口返回的用户信息中包含：

```json
{
  "success": true,
  "user": {
    "username": "xxx",
    "daily_max_calls": 6,
    "daily_calls_count": 2,
    "remaining_calls": 4
  }
}
```

### 3. 修改用户的每日最大调用次数

`POST /api/auth/update-daily-max-calls`

**请求体：**
```json
{
  "daily_max_calls": 20
}
```

**响应：**
```json
{
  "success": true,
  "message": "每日最大调用次数已更新为 20 次",
  "daily_max_calls": 20
}
```

**注意：** 需要用户登录（Bearer Token）

## 工作原理

1. **自动重置**：每天第一次调用时，如果 `last_call_date` 不是今天，会自动将 `daily_calls_count` 重置为 0
2. **计数增加**：每次成功创建任务时，`daily_calls_count` 自动 +1
3. **限制检查**：在创建任务前检查，如果 `daily_calls_count >= daily_max_calls`，拒绝请求

## 使用示例

### 修改用户的调用次数限制

```python
import requests

token = "your_jwt_token"
headers = {"Authorization": f"Bearer {token}"}

# 将用户的最大调用次数设置为 50
response = requests.post(
    "http://127.0.0.1:8000/api/auth/update-daily-max-calls",
    headers=headers,
    json={"daily_max_calls": 50}
)
print(response.json())
```

## 注意事项

1. 匿名用户（未登录）每日调用次数 3 次
2. 调用次数在每天 00:00 后自动重置（基于 `last_call_date`）
3. 修改 `daily_max_calls` 不会影响当天的已使用次数
4. 如果任务创建失败，调用次数仍然会被扣除（因为检查在任务创建前进行）
