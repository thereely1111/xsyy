【知识域表达：统计概率类】—— 覆盖"数据收集 / 统计图表 / 集中量数 / 概率"

（当且仅当题目属统计/概率知识域时叠加本层；与 00_base/学段风格冲突时，
方法纪律 > 画面纪律 > 学段风格 > 本层。）

0. 学段要点（本层动画必须区分小学 / 初中）：
   - 小学：以"读图、分类、直观比较"为主——条形图/折线图/扇形图的认识与读数，
     平均数/中位数/众数的直观意义；少用公式，多用"数一数、比一比"的具象过程。
   - 初中：在直观基础上加**计算与推断**——加权平均、方差（波动大小）、频数分布
     直方图、概率的古典概型与树状图/列表法；结论要有数值支撑，且"看图说话"
     必须和图中具体数值对得上。

1. 数据忠于题干（最高优先级，最易错）：
   - 图中所有数值必须来自题目，禁止编造/脑补数据；数值标注与题干口径一致
     （频数 / 频率 / 百分比 / 圆心角）。
   - 样本总量、单位、类目名逐字照抄题干；若题干给的是原始数据表，先"数"再"画"。

2. 统计图"生长动画"（每类图的规范）：
   - 条形图：画带箭头的坐标轴 + 刻度（纵轴从 0 起，标单位）；柱从 0 基线逐条长高，
     柱顶标数值，类目轴标签清晰不重叠；柱宽一致、间隙均匀。
   - 折线图：先描点（点坐标标注）→ 再按顺序连线；趋势（上升/下降/平稳）高亮；
     纵轴刻度规范，转折点可加文字说明。
   - 扇形图：先画整圆，再按"圆心角 = 360°× 占比"逐个展开扇区；百分比标签放扇区
     外引线或扇区内；所有扇区占比之和必须等于 100%（自检：拼不满整圆即错）。
   - 频数分布直方图：组距一致、组界不重叠；纵轴为"频数"，横轴为"数据区间"；
     各矩形等高宽一致、紧挨无间隙。

3. 集中量数（平均数/中位数/众数/方差）：
   - 平均数：用"移多补少"或"求和均分"动画演示（先求和再除以个数），加权平均要
     标每个数的"权"；禁止只抛公式不演示过程。
   - 中位数：先把数据从小到大排序（排序动画），再圈出"最中间"的一个或两数取平均；
     数据个数为偶数时明确"取中间两数平均"。
   - 众数：统计各数出现次数（计数动画），出现最多者高亮；提醒"可能多个/可能没有"。
   - 方差：演示"每个数减平均数 → 平方 → 求平均"的离差过程，用柱高表示离差平方，
     直观对比"哪组数据更稳（方差小）"。

4. 概率（古典概型为主）：
   - 样本空间：用转盘 / 摸球 / 掷骰等拟物图形，把所有等可能结果**逐个点亮**，
     做到"不重不漏"（这是概率动画的核心，易漏结果要显式列出）。
   - 有利结果：在样本空间中高亮"满足条件"的结果；概率 = 有利 / 总结果，用分式标注。
   - 树状图 / 列表法：分支/单元格逐个展开动画，路径或单元格对应一个等可能结果；
     两步及以上务必用树状图或表格枚举，禁用"心算组合"。
   - 频率估计概率：用"试验次数↑ → 频率趋于稳定值"的长条/折线稳定演示（如需要）。

5. 图与文一致（收尾必做）：
   - 气泡/步骤文字引用图表中的具体数值，箭头指向图上对应柱/点/扇区；
   - 最后做"看图说话"式结论（谁最多 / 整体趋势 / 可能性多大），结论必须能被图证实；
   - 小学题结论口语化（"最多的是…"），初中题结论加数值与推断（"方差较小，更稳定"）。
