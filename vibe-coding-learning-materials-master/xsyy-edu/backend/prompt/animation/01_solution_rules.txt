【完整解答纪律层 01_solution】—— 右侧"完整解法"卷轴的书面文本纪律（动画/解答一体）

（页面右侧"完整解法"卷轴由动画数据包 steps[] 的 title + description 逐条连读而成；
本层约束这两项文本，使整卷连读就是一份标准、完整、可照抄的书面解答。
动画/解答不分产物、不生成独立 solution_data.json——步骤即解答，一步不缺、不讲两套。）

1. 【title 短标题】每一步 title 用书面解题动作命名（10 字内）：
   应用题：审题 / 设未知数 / 列方程 / 解方程 / 检验 / 作答
   计算题：列式 / 通分 / 计算 / 化简 / 检验
   几何题：已知 / 求证 / 证明 / 计算 / 作答
   函数题：设解析式 / 代入求参 / 画图 / 求交点 / 判解集
   禁止用"第一步/第二步"等序号当标题，禁止用"看这里/注意"等口语。

2. 【description 是书面解答正文】description 与该步 bubbleText（画布气泡，
   口语简单讲解）严格分工：气泡可以"你看，把等式两边都减去 3…"；
   description 必须写成规范书面步骤，直接可抄写，例如
   "方程两边同时减去 3，得 2x = 8；两边再除以 2，得 x = 4。"
   禁止把 description 写成对画面的解说（"画面中可以看到…"）、感叹句或残句。

3. 【整卷连读 = 一份完整解答】所有步骤的 title+description 串起来必须是一份
   完整、连贯、可独立阅读的书面解答：
   - 步骤齐全不跳步：关键变形/公式/代入/计算中间量都要出现，禁止只给答案；
   - 推导前后衔接：后一步直接承接前一步的结果，中间量连续、无断层；
   - 算式规范：数字算式与 $公式$（KaTeX）均可，公式须语义完整（如
     $2x+3=11$，不要裸写符号）；
   - 末步收尾：应用题以"作答"句结束（含单位），证明题以"∴"结论结束，
     方程/计算给出检验或至少口头验证，杜绝"讲完思路没给结论"。

4. 【按题型给标准结构】书写骨架按题型模板（与动画同方法，禁止中途换方法）：
   - 应用题：设未知数（标明单位）→ 找等量关系列式 → 解出 → 检验合理性 → 作答；
   - 解方程/不等式：注明两边同加/同减/同乘/同除的变形依据，不等号变号处显式说明；
   - 几何证明：已知 → 求证 → 证明（每步注明依据：全等判定/角的关系/性质定理）→ ∴；
   - 函数/图象：由"设通式"到"代入点求参"到"写解析式"逐步落定；
   - 统计/概率：先列数据/样本空间，再算，最后下结论，禁止跳过计算直接报数。

5. 【学段语气】小学题：文字浅白、步骤间多给一句过渡解释，但不失书面完整；
   初中题：按教材规范书写（几何用"∵/∴"，方程写"解：…"，分式注明检验）。

6. 【复合多小题】每题问前用「【第(N)问】」标注，每问独立完整
   （解 → 列式/推导 → 计算 → 作答），不得因"前面算过"省略本问作答句；
   跨问沿用中间量直接引用即可，不要重复推导。

7. 【一致性底线】右侧卷轴的写法、中间量、顺序必须与左侧动画演示的同一套解法
   完全一致——动画怎么推，文字就怎么写；禁止出现动画没演示的另一套方法/口径。
