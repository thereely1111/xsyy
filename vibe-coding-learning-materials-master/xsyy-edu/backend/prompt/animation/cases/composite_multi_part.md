# 复合多小题通用结构示范

适用：题面含 （1）（2）（3）… 多个小问的数学综合题（函数+几何、代数+统计等任意跨域组合）。

## 解题与分镜通法（务必逐问落实）

1. **先整体读题、识别小题数**：用 （1）（2）（3） 把题切成若干子问；每问判知识域
   （函数 / 几何 / 统计…），跨域则坐标系或核心图形全程复用。
2. **建"共享舞台"**：若多问共用同一幅图（最常见是坐标系），先一次性画稳
   坐标系/已知图形，放进 persistent-layer；后续每问只叠加当前问的临时动作。
3. **逐问独立完整解答**：每问都走"解 → 列式/推导 → 计算 → 作答"，不得因前面问过
   就省略本问作答句；step.title 用「【第(N)问】」前缀分组。
4. **中间量跨问延续**：上一问求得的关键量（参数、交点坐标、面积值）在后续问直接引用，
   不重复求解；用 persistent 标注呼应前问，让学习者看清"前面得到了什么"。
5. **切问防跳变**：切到新问用 autoCenterOnStep 轻微归位但不抖动，前问成果保持可见。
6. **末问收尾**：最后一问给最终答案，并做验证（代入/数形核对）。

## 与动画纪律的关系

- 复合题 steps 数量通常偏多（8~15），但每问内部仍"一拍一个数学动作"；
- 临时层（轨迹/高亮/辅助线/笔迹）严格 `sceneStep === N`，切步即消失；
- 共享坐标系列入持久层 `sceneStep >= 1`，不被临时层覆盖或重画；
- 4a~4f 同屏纪律照常执行（尤其多问叠加时更易爆"字压字/图压文"，务必逐项自查）。
