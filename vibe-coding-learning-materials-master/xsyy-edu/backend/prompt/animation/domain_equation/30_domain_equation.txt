【知识域表达：方程与不等式】—— 覆盖"一元一次方程 / 二元一次 / 一元二次 / 分式 / 不等式"

（当且仅当题目属方程与不等式知识域时叠加本层；与 00_base/学段风格冲突时，
方法纪律 > 画面纪律 > 学段风格 > 本层。本层与 domain_numbers 常并存：
解方程前的"列关系式"可能用到数与式表达，二者口径一致。）

0. 学段要点（本层动画必须区分小学 / 初中）：
   - 小学（高段）：用**天平 / 实物**讲"等量关系"——两边同加同减同乘同除仍平衡；
     不强调代数符号，重在"为什么相等"。
   - 初中：过渡到规范代数步骤——设未知数 → 列方程 → 解方程（按法则逐步）→ 检验；
     每步都要有可见的数学动作，禁止"跳步给结果"。

1. 表征模型·按题型选（打破"千题一天平"，治好"太普通"）：
   - 同一题固定一种主模型贯穿，不混用；模型服务于"讲清这一步怎么变"，不为装饰。
   - 小学（高段）引入等量关系：用天平 / 实物（两边同加同减仍平衡）讲"为什么相等"；
     不强调代数符号，重在直观。
   - 初中解方程：不必每步画天平。直接用"等式变形动作"做动画——两边同减某量时，
     该项从等式一侧飞到另一侧并翻转符号（移项变号）；同除以 a 时系数收缩为 1；
     用平移 / 翻转 / 缩放表达变形，等式始终居中对齐、等号同基线（见第 9 条纵向排列）。
   - 二元一次方程组：用"大括号联立系统"呈现；代入消元时把被代入式高亮"传送"进另一式，
     加减消元时两式对齐、消元项同色抵消；求得 (x,y) 后 persistent 标注并双重检验。
   - 列方程解应用题：线段图 / 表格 / 天平移项 按题意选最直观的一种，未知量 x 标在对应量上，
     "找等量关系"用高亮连线把两边相同量连起来。
   - 不等式：用数轴（空心 / 实心圆 + 箭头）或天平明显倾斜表达方向；乘除负数变号必须显式高亮。
   - 含几何 / 函数的方程（如圆方程、求函数交点）：直接用坐标系表达，不套天平。

2. 一元一次方程（最基础，必须讲透）：
   解的标准五步，每步独立成 step 且只做一件事：
   - 去分母：两边同乘各分母的最小公倍数，标注"每一项都乘"，常数项易漏乘要圈出；
   - 去括号：正括号不变、负括号"全变号"，变号项逐个翻转高亮（易错点前置）；
   - 移项：把含未知数的项移到一边、常数项移到另一边，"移项要变号"用颜色翻转该单项；
   - 合并同类项：化为 ax = b（同色框选同类项，系数相加）；
   - 系数化 1：两边同除以 a，得 x = b/a；若 a<0 不等号方向变化（不等式情形）。
   末步必须**代入检验**：把 x 代回原方程左右，两边相等才画"√"。

3. 二元一次方程组：
   - 代入消元：从一个方程解出一个字母，代入另一个方程（被代入项用高亮"传送"动画）；
   - 加减消元：两式同乘适当数后相加 / 相减消去一个未知数，消元目标项高亮；
   - 求得一组解 (x,y) 后用 persistent 标注，并可选"代入两个方程双重检验"。

4. 一元二次方程：
   - 配方法：移项 → 二次项系数化为 1 → 两边加 (b/2)² 凑完全平方式 → 开平方
     （用"正方形分割补成完整平方"的面积模型辅助理解）；
   - 公式法：直接套 x = (−b ± √(b²−4ac)) / 2a，判别式 Δ 的符号决定实根个数（Δ<0 无实根）；
   - 因式分解法：十字相乘 / 提公因式，把方程写成"积=0 ⇒ 各因式=0"。

5. 分式方程：
   - 去分母化为整式方程（同乘最简公分母，标注乘的式子，且**每一项**都乘）；
   - 解出根后必须**验根**：代回最简公分母，分母为 0 的是增根，须舍去（用"✗ 增根"标注）。

6. 不等式（一次）：
   - 解集在数轴上表示：边界点用**空心圆（不含）** / **实心圆（含）**，方向用箭头延伸；
   - 乘除负数时**不等号方向反转**，该步必须显式标注"变号"并高亮；
   - 解集写法与数轴标注一致（如 x > 2 对应 2 右侧空心 + 右箭头）。

7. 列方程解应用题（把"题"变"式"）：
   - 先画**等量关系**（线段图 / 表格 / 天平移项），把未知量明确标在图上；
   - "设未知数"用 x 标注在对应量上；"找等量关系"用高亮连线把两边相同量连起来；
   - 单位与量纲一致；答句单独成一步，且回答要回到题目原问（不只读 x=…）。

8. 文字与公式：数字 / 解用醒目但克制的强调（朱砂红）；**scene_svg 内禁用 LaTeX 控制符**，
   等号 / 不等号用 Unicode（= ≠ < > ≤ ≥ ≈）；steps 的 description/bubbleText 支持 $公式$。

9. 解题说明文字与天平标注的图层归属（防覆盖硬纪律，违反会被后续动画压住）：
   - 每一步的"操作说明文字"（如"保持等式两边相等""两边同减5""移项要变号"
     "两边同除以3""每一项都要乘"）属于**本步临时讲解**，必须 x-show="sceneStep === N"，
     切到下一步立即消失，绝不残留压住变形后的方程或新动画元素；
   - 天平模型的"平衡/倾斜"状态标注、"左盘=右盘"文字同样随对应 step 显隐，
     不得长期挂在画布上被后续步骤覆盖；
   - 若某步结论（如已化简的 ax=b、最终 x=…）需保留为后续已知，放 persistent
     (x-show="sceneStep >= N") 并**降为低对比**（淡灰 #b9ad95、字号缩小、挪到左上/角落），
     不得与当步焦点方程同区抢视线；
   - 文字与其底色圆角矩形必须**同 x-show、同图层**：禁止矩形已消失而文字残留，
     或文字浮在旧坐标被新线条/图形压住一半；
   - 多步方程式纵向排列时，等号用同一 x 基线对齐，右侧推导文字不得压住左侧方程；
   - 自检：逐 step 脑演——本步说明文字在 sceneStep+1、+2 时是否还显示？若会显示，
     它必须要么消失（=== N）、要么降对比并挪到不冲突区。
