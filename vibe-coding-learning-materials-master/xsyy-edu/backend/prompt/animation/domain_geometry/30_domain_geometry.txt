【知识域表达：几何类】—— 覆盖"图形与几何"

（当且仅当题目属几何类知识域时叠加本层；与 00_base/学段风格冲突时，
方法纪律 > 画面纪律 > 学段风格 > 本层。）

1. 图形必须数学精确：
   - 垂直真垂直、平行真平行、等长真等长、圆心真在圆心上、中点真在中点；
     先算坐标再画，禁止"看着像"的近似摆放。
   - 标注规范：∠A、AB=CD、a⊥b、a∥b、直角符号；弧线标角、小竖线标等长。
2. 画图纪律：
   - 用尺规感表达作图（先定已知、再作辅助线、后标注），不是一笔画完。
   - 同一图形跨步保留时只画一次，后续步只叠加高亮/辅助/标注，禁止复制整图。
3. 辅助线是"关键教学动作"：
   - 新辅助线出现用 sceneStep === N 高亮该步，气泡解释"为什么这样作"；
   - 辅助线用虚线/不同色与已知线区分，切步即消失（除非后续仍引用）。
4. 常见证明/计算的分镜骨架（初中）：
   读图标已知 → 分析目标 → 引辅助线 → 证全等/相似/列式 → 结论 → 检验。
   - 全等/相似：对应边/对应角用同色系高亮配对，旋转/平移演示叠加对应。
   - 对称：对称轴虚线 + 翻折动画；旋转：旋转轨迹弧 + 对应点连线。
   - 面积/周长：分割法动画演示（切、补、移），标注每块尺寸。
5. 立体图形：展开图动画、三视图对应关系、表面积=展开面积、体积公式推导示意。
6. 圆与扇形：圆心角/半径标注；弧长与面积公式给"推导路径"而非只写结论。
7. 坐标系几何：坐标轴、象限、点坐标标注清晰；两点距离/中点用网格辅助。
   - 坐标轴上每条线（轴/箭头/网格/刻度/连线/辅助线）都必须带 id + class="svg-elem"
     + 正确 x-show；网格归入 persistent <g>，禁止裸 <line>。详见 00_base 线条语义纪律。
8. 【充分利用画布·防压盖】几何图常元素密集，更要注意：
   - 整幅 820×620 可用（左上无禁区），图形/标注均匀铺开，不要缩在中心一小块；
     坐标轴、图形主体撑满主要区域，把交点、辅助线、面积阴影都画在留白充足的对应位。
   - 任意两元素不得重叠：图形与图形、标注与图形、文字与文字间距 ≥12px；
     字母标注（A/B/O/∠1）放图形外侧 ≥10px 处，禁止压在边线上或半隐半露；
     多个角/多段弧的标注用不同方位错开，禁止叠在一起。
   - 尺规作图分步演示时，辅助线/高亮属临时层（=== N），切步即消失，不得与后续
     图形叠压；已证结论（如全等符号、面积值）若保留须降对比挪角。

scene_svg 内禁止 LaTeX；几何量（∠、⊥、∥、√、π、°）用 Unicode。
