【知识域表达：数与式】—— 覆盖"整数/分数/小数/百分数/有理数运算 / 代数式 / 整式 / 分式"

（当且仅当题目属数与式知识域时叠加本层；与 00_base/学段风格冲突时，
方法纪律 > 画面纪律 > 学段风格 > 本层。）

0. 学段要点（本层动画必须区分小学 / 初中）：
   - 小学（1-6 年级）：抽象变具象——用实物、数轴、切饼等直观图形讲算理，
     不直接甩竖式；节奏慢、字大、配色活泼（见 stage_primary 风格层）。
   - 初中（7-9 年级）：逐步过渡到符号化——有理数运算讲"符号法则"、代数式讲
     "合并同类项"、整式/分式讲规范变形；允许公式但每步要有可见的算理动作。

1. 数与运算的直观表达（小学为主，初中仍可用）：
   - 加减：数轴跳格子（向右加/向左减），或实物/方块增减；算一步亮一步，
     旧算式淡出不堆叠。
   - 比较大小：高低柱 / 天平 / 数轴定位，不靠心算叙述。
   - 分数：切饼 / 分物演示"平均分"，分子分母用圆/矩形分区标注，约分=合并相同
     小份；异分母加减必须先"通分"再同分母相加（通分过程可动画）。
   - 小数 / 百分数：用"满 10 进 1"的计数块，或"百分数=每 100 份中占几份"的
     百格图（100 格方阵高亮对应格数）。
   - 负数：温度计 / 数轴左右两侧，强调"0 是分界"，加减负数用"反向跳格"。

2. 四则混合与竖式（小学高段→初中）：
   - 竖式 / 列式：步骤化展开，逐行对齐数位；进位 / 退位点用小字标注并高亮该步。
   - 运算顺序：用"先括号、再乘除、后加减"的分步聚焦，禁止一步出结果。
   - 简便运算（凑整 / 分配律）：把"拆与合"的过程画出来（如 25×44 = 25×4×11），
     不直接给变形后式子。

3. 代数式与整式（初中）：
   - 用"字母代表数"的具象过渡：先给数值例子，再替换为字母，建立"式=一类数"的直觉。
   - 合并同类项：同类项用同色框选配对，合并动作逐组亮；系数相加、字母部分不变。
   - 去括号：正号去括号不变、负号去括号"全变号"——变号项逐个翻转高亮（易错点前置）。
   - 幂的运算 / 乘法公式：用面积模型演示 (a+b)² = a²+2ab+b²（大正方形分割为四块），
     比纯符号更抗遗忘。

4. 分式初步（初中）：
   - 约分 = 分子分母同除以公因式（用"划掉相同因子"动画）；
   - 通分 = 找最简公分母后扩分（扩分后分子分母同乘，标注乘的数）；
   - 分式加减必须"先通分再加减"，禁止跨分母直接加减。

5. 文字与公式：数字 / 单位用醒目但克制的强调（朱砂红），公式放 foreignObject 或用
   Unicode 预计算；**scene_svg 内禁用 LaTeX 控制符**；steps 的 description/bubbleText
   支持 $公式$（KaTeX 渲染）。
