# 【函数曲线族】坐标系 + 平滑完整函数曲线（直线 / 抛物线 / 双曲线）

- pattern_key: `function_curve`
- 文件：`scene_patterns/50_pattern_function_curve.md`
- 优先级：**画法硬规范**（命中即必须遵守；与 `domain_function` 描述层互补——本文件约束"曲线必须长成什么样 + 怎么画 + 怎么动"，不是仅供参考的样例）
- 命中题型（由 `content_profile` 的 `question_type` 注入）：一次函数 / 二次函数 / 反比例函数 / 反比例函数与一次函数交点 / 图象不等式
- 适用特征：题面要求画出函数图象（一次/二次/反比例）、求解析式后作图、图象交点、或图象判读不等式解集。

> 本 pattern 专门纠正"函数画不完整 / 坐标系缩一角 / 双曲线两支不对称 / 曲线锯齿"等失真。方法纪律 > 画面纪律 > 学段风格 > 本层。

## 一、画法硬规则（违反即被 Lint 打回）

1. **坐标系 = 舒展铺满中部带，禁止缩进中心小方块**：
   - x 轴从约 x=70 横展到 x=750，y 轴从约 y=518（底端）上到 y=205（顶端），原点 O 按数值范围定（一次函数常偏左下方、二次函数常偏中心下方、反比例置绘图区几何中心）；
   - 坐标轴 / 网格 / 刻度归入 persistent 的 `<g>`（`x-show="sceneStep >= 1"`），全程贯穿复用，禁止缩在中心一小块；
   - 严禁把整幅图画进 (410,310)±70 的中心盒——那是实体类约束，坐标系类题目豁免（见 `00_base` 第 84 行）。
2. **曲线 = 平滑 + 完整 + 采样点足够密**（点位数量见第三节）：
   - 一律平滑（path 贝塞尔或足够密折线），**禁止尖角折线、禁止只画半段、禁止曲线在可视区内凭空截断**；
   - 曲线两端须自然延展到坐标轴附近（抛物线压到 x 轴范围边界 / 对称轴为界；双曲线无限逼近坐标轴但不相交）；
   - **每个采样点像素坐标都必须落在 viewBox 0–820 × 0–620 内**，禁止任何点越界被裁切（这是"画不完整"的头号成因）。
3. **数学→像素坐标映射配方（必须照此算，禁止凭感觉估）**：
   - 设数学范围为 x∈[xmin,xmax]、y∈[ymin,ymax]，画布像素区 x∈[70,750]、y∈[205,518]：
     ```
     sx = 70  + (x - xmin) * (750 - 70) / (xmax - xmin)
     sy = 518 - (y - ymin) * (518 - 205) / (ymax - ymin)   # 注意 y 轴向下，需翻转
     ```
   - 原点 O 的像素坐标 = 同一公式代入数值原点；刻度数字贴轴外侧、不压曲线。
4. **关键特征点必须标注**：顶点（抛物线）、对称轴（虚线）、交点 A/B（双曲线与一次/坐标轴）、渐近线方向（双曲线用极淡矩形 / 虚线提示，**禁止穿越画面的红色斜构造线**）。
5. **颜色纪律**：曲线 = 变量蓝 `#2f5fde`；顶点 / 交点 / 关键标注 = 朱砂 `#d6432f`；坐标轴 / 网格 = 墨 `#2b2b2b` 与浅色网格 `rgba(43,43,43,.10)`；提示性辅助 = 鎏金 `#c8901a` 或中性灰。**禁止** `#8a1c1c` 大面积铺底、`#78716c/#44403c/#a8a29e` 灰系作大块遮罩。
6. **曲线生长动画技法（唯一推荐，禁止用别的方式表现生长）**：
   - 给曲线 `<path>` 加属性 `pathLength="1"`，首步设 `style="stroke-dasharray:1; stroke-dashoffset:1"`（路径不可见），后续步把 `stroke-dashoffset` 从 1 渐变到 0 即平滑铺开；
   - 复用模板已有 CSS transition（transform / opacity 缓动）配合，**禁止用"淡出再淡入"的瞬移**表现生长。

## 二、场景骨架（尺寸 / 比例尺为示例，数据按本题替换）

```
820×620 画布，坐标系铺满中部带：
- 坐标轴：x 轴 y≈518 从 x=70 到 x=750（带正方向箭头）；y 轴 x≈（按原点定）从 y=518 到 y=205；
  原点 O 像素坐标 = 映射配方代入数值原点；刻度数字贴轴外侧、不压曲线；
- 网格（可选，浅色虚线 rgba(43,43,43,.10)）辅助定位，不喧宾夺主；
- 曲线：按第三节点位列表取点 → 映射成像素 → path 平滑连接；
- 顶点 / 交点：高亮圆点 + 字母 / 坐标标注，落在曲线外侧空白处，用淡色引线（避免压线）；
- 顶部计算带（y≈60）：解析式、关键量；底部结论带（y≤600）：结果 / 解集。
```

## 三、各函数类型画法（含具体点位数量与示例）

### 3.1 一次函数 y = mx + n（直线）
- 取 2~3 个 x 求对应 y → 描点 → 直线连接（**非折线、非多段**）；
- 点位：至少 2 个端点（曲线两端须到坐标轴附近）+ 1 个校验点；
- 例：y = 2x + 1，x∈[-3,4] → 点 (-3,-5)、(0,1)、(4,9) 三点共线连成直线。

### 3.2 二次函数 y = ax² + bx + c（抛物线）
- **顶点必取**：x_v = -b/(2a)，y_v 代入；左右各 ≥6 个均匀点，共 ≥12 点；
- 开口方向由 a 定，对称轴 x = x_v（虚线）；曲线两端自然压到 x 轴范围边界或 y 轴边界；
- 例：利润 W(x) = -40x² + 600x + 10000，x∈[0,25]，顶点 (7.5, 12250) → 像素顶点约 (274,223)，两端 (70,277)、(750,518)。（完整样例见案例层。）

### 3.3 反比例函数 y = k/x（双曲线，必须中心反射对称）
- 原点 O 置**绘图区几何中心**（禁止塞左下角）；第一支取 ≥12 个均匀密集点（靠近渐近线处加密）；
- 第二支直接对第一支做**原点中心对称点反射 (x,y)→(-x,-y)** 生成，保证两支对称、等长、等曲率；
- 每支平滑延伸、逼近坐标轴但不接触；k>0 在一、三象限，k<0 在二、四象限；
- **禁止**两支独立采样导致一长一短 / 一胖一瘦，禁止尖角折线，禁止保留红色斜构造线。

### 3.4 图象不等式解集（双曲线在直线上方的 x 区间等）
- 在交点处切分区间，用阴影 / 填充高亮"上方"区域，逐区间读 x 范围；
- 双曲线在 x=0 处断开 → 解集按 x<0 与 x>0 分段写（如 x<-1 或 0<x<2）。

## 四、曲线生长动画分步（示例：二次函数 4 步）

```
step1 建系：坐标轴 persistent 出现（x-show="sceneStep>=1"），曲线 pathLength=1 dashoffset=1 不可见
step2 描关键：顶点 / 交点高亮圆点出现
step3 生长：曲线 stroke-dashoffset 1→0 平滑铺开（配合 transition）
step4 聚焦：对称轴虚线 + 顶点标注 + 顶部解析式 / 底部最值结论
```

（一次 / 反比例同理：先建系 → 标点 → 生长 → 聚焦。）
