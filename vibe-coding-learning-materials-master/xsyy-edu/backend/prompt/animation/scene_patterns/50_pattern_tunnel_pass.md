# 【隧道/过桥族】主体沿通道"完全通过"，总路程 = 通道长 + 主体长

- pattern_key: `tunnel_pass`
- 文件：`scene_patterns/50_pattern_tunnel_pass.md`
- 优先级：**画法硬规范**（命中即必须遵守；与案例层 case 不同——本文件约束"场景必须长成什么样 + 怎么动"，不是仅供参考的讲解样例）
- 命中题型（由画像 question_type 注入）：火车过隧道 / 火车过桥 / 汽车过桥 / 船过桥洞
- 适用特征：题面含运动主体（火车/汽车/船）沿固定通道（隧道/山洞/桥/桥洞/闸）从一端**完全通过**到另一端，求时间/速度/长度；核心公式 **总路程 = 通道长 + 主体长**（"完全通过"）；若问"车头到洞口/车身全部在洞内"则路程=通道长-主体长，按题意换算。

## 一、画法硬规则（违反即被 Lint 打回）

1. **通道 = 侧面一条浅色圆角扁带**（不是实心山丘、不是灰色大遮罩、不用 evenodd 挖空）：
   - 填充浅中性色（米色 `#e9e2d2`），描边同系 `#b9ad95`，圆角 rx≥8；
   - 带上方标通道长：`隧道长 1000 m` / `桥长 850 m`（用 `{channel_len} m` 占位）；
   - 带两端标 **入口 / 出口**（隧道、山洞）或 **桥左端 / 桥右端**（桥），或 **桥洞左 / 桥洞右**（船）；
   - 船过桥洞变体：带代表**水面**，桥洞画成水面上方拱形/矩形开口（留出**垂直净空**），水面带上方空间示意天空，不画灰色实心山。
2. **运动主体 = 一个带唯一 `id` 的彩色圆角矩形/组（mover）**：
   - 火车/汽车：彩色车身（火车蓝 `#2f5fde` 或朱砂 `#d6432f`；汽车可换鎏金 `#c8901a`），白窗 + 白色标签 `火车 200 m`（`{vehicle_len} m`）；
   - 船：船形用圆角矩形+斜切造型示意，标签 `船 30 m`；
   - **紧贴带的上沿水平滑行**：mover 底边与带顶边相接（车/船在带上方，不是悬浮、不压进带内）；船贴水面带顶边。
   - 主体自身**禁止带 transform 属性**（由模板 style.transform 驱动），静态定位写在外层包裹 <g> 上。
3. **颜色纪律**：只允许模板三色体系 + 中性色 —— 变量蓝 `#2f5fde` / 朱砂 `#d6432f` / 鎏金 `#c8901a` / 墨 `#2b2b2b` / 纸 `#f4efe3` / 米带 `#e9e2d2` 与描边 `#b9ad95`；**禁止** `#8a1c1c` 大面积铺底、`#78716c/#44403c/#a8a29e` 灰系作主体或遮罩大块。
4. **运动序列（motions）**：每个需要移动的 step 都输出 motions（对象式 `{"train": "translate(x,0)"}`），位移按比例尺算准；**相邻步位移 ≥40px**；全程每步都在推进，**末步也要动到"尾部完全离开出口"**，禁止最后两步同值"停摆"。
5. **叙述与结论**：用顶部小字逐步叙述位置（①车头刚到入口 → ②车头进洞 → ③车头到出口 → ④车头出洞 → ⑤车尾离洞）；关键步配**鎏金虚线** + 总路程文字（如 `总路程 = 1000 + 200 = 1200 m`），后随公式行 `t = 总路程 ÷ 速度 = 1200 ÷ 20 = 60 秒`。

## 二、场景骨架（尺寸/比例尺仅为示例，数据必须按本题替换）

```
820×620 画布，画面明亮、横向构图：
- 米色圆角带：x≈120 y≈250 w≈560 h≈70（{channel_len}=1000m 时比例尺 ≈0.56px/m）
  隧道变体两端文字：「入口」@(120,~230) /「出口」@(680,~230)；带中央上方「隧道长 1000 m」
- 运动主体 mover：初始车头贴入口内侧，底边 y≈248 贴带顶 y=250；
  车身 w = {vehicle_len} × 比例尺（如 200m → 112px），高 ~44px，圆角 rx≈10，
  白窗 2 个 + 白色车身标签（如「火车 200 m」）
- 顶部叙述文字行：y≈60（逐步位置小字，灰/墨低饱和）
- 鎏金总路程虚线：y≈340（第 2~3 步起出现，直线从入口画到出口上方）
- 公式行：y≈430（第 4 步起出现：t = 总路程 ÷ 速度）
```

变体差异（其余与骨架一致）：
| 变体 | 通道带 | 主体 | 标注 | 特殊约束 |
|---|---|---|---|---|
| 火车过隧道/过山洞 | 米色带=地面隧道 | 蓝/朱砂火车 | 入口/出口 + 隧道长 | 无（最简） |
| 火车/汽车过桥 | 米色带=桥面，带下可画 2~3 个桥墩（浅中性）表示河 | 火车或汽车 | 桥左端/桥右端 + 桥长 | 无 |
| 船过桥洞 | 带=水面（米色带顶边即水面线），空中桥洞用拱形/矩形开口 + 净空高标注 | 船 | 桥洞左/右 + 桥洞宽 + 净空高 | 多一步"船高≤净空"判定步（垂直语义，不水平滑入墙体） |

## 三、运动序列约定（示例 5 步：总位移 = (通道长+主体长)×比例尺）

比例尺 0.56px/m：隧道 1000m + 车 200m → 总位移 672px。mover 起点 x=60（车头贴入口 x=120 左侧留白），末点 x=732-车身宽：

```
step1 审题：train translate(0,0)（静止，叙述：车头刚到入口）
step2 定路程：train translate(280,0)（车头到隧道中段）→ 金虚线+总路程文字出现
step3 理过程：train translate(560,0)（车头到出口）
step4 列式：  train translate(620,0)（车头出洞 60px）→ 公式行出现
step5 检验：  train translate(672,0)（车尾离洞，末步仍在动）
```

> 若题目问"全部在洞内的时间"等非完全通过情形，按题意调整终点与中间步叙述，但**每步位移仍须 ≥40px 且末步在动**。

- [ ] 入口/出口（或桥左/右、桥洞左/右）、通道长、主体长 四类标注齐全？
- [ ] 每步 motions 位移按比例尺算准、相邻步 ≥40px、末步仍在动（无"最后两步同值"）？
