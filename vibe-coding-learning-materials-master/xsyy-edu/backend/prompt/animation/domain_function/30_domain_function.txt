## 画布布局（函数题专属 · 恢复舒展坐标系，这是动画"好看"的关键）
   - 函数题的视觉主体 = 坐标系 + 图象，必须**舒展铺满中部带**，绝不能被压成中心小方块：
     · 先建立坐标系：x 轴从约 x=70 横展到 x=750，y 轴从约 y=510（底端）上到 y=210（顶端），
       原点 O 按数值范围定（一次函数常偏左下方、二次函数常偏中心下方、反比例按象限定），
       **不强行塞进 (410,310)±70 的小框**——那是实体类题目的约束，函数坐标系豁免；
     · 坐标轴/网格/刻度归入 persistent 的 <g>（x-show="sceneStep >= 1"），全程贯穿复用，禁止缩在中心一小块；
   - 图象（直线/双曲线/抛物线）按解析式**平滑铺满可视区**：取足够密的点连线，
     顶点/交点/特殊点用高亮圆点 + 字母标注，曲线自然延展到坐标轴附近（双曲线逼近渐近线）；
   - 文字标注（解析式、点坐标、解集）放在图象空白处或顶部计算带，用第 13 条朱砂引线指向对应图形；
   - 渲染端已对整段动画做全步进自动居中——你只需保证坐标系铺满中部带、图象舒展、
     元素围绕中心不挤向一侧即可，无需手动把坐标系缩进几何中心。
   - 常见"丑"的成因（务必避免）：坐标系缩在画布中央一小块、图象只占中部 1/3、
     原点偏离导致图象偏在一角、坐标轴没贯穿导致曲线悬空、双曲线两支不对称
     （未做原点中心反射、原点没放绘图区中心、两支独立采样密度不一）、把整幅图压进 410±70 中心盒、
     曲线用直线/尖角硬拼、在最终画面保留红色构造斜线、标签压在曲线上。

1. 坐标系绘制纪律（函数题的"地基"，必须先画稳再画函数）：
   - 画双向箭头坐标轴 x/y，标原点 O、正方向箭头；按数值范围定刻度，刻度数字
     贴轴外侧、不压曲线；必要时刻度网格用浅色虚线（辅助，不喧宾夺主）。
   - 象限标注：第一/二/三/四象限用淡色角标或只在关键区提示，禁止遮挡图象。
   - 已知点（如 A(2,4)、B(-1,-2)）用实心圆点 + 字母标注，坐标值用小字写在
     点旁、避开其他元素（参见 00_base 的重叠纪律）。
   - 坐标系本身放 persistent-layer（跨小题保留），仅当前步高亮的元素走临时层。
   - 坐标系全部线条（轴/箭头/网格/刻度/交点圆点/曲线/连线/面积阴影边）每条必须带
     id + class="svg-elem" + 正确 x-show：轴与网格归入 persistent 的 <g>（x-show="sceneStep >= 1"），
     组内每条线仍各自带 id+class；临时高亮线（交点圆点、OA/OB 连线、阴影边）用 sceneStep === N。
     严禁生成不带 id/class 的裸 <line>。

2. 函数图表达：
   - 一次函数 y=mx+n：先列表（取 2~3 个 x 求对应 y）→ 描点 → 连线成直线；
     斜率 m 决定倾斜、截距 n 决定与 y 轴交点，连线用平滑直线（非折线）。
   - 反比例函数 y=k/x（k≠0）：取 k 符号对应象限的点列表描点 → 双曲线两支
     渐进行为（无限逼近坐标轴但不相交）；k>0 在一、三象限，k<0 在二、四象限。
   - ⚠️【双曲线必须严格中心对称的构造法】反比例函数图象是**关于原点中心对称的
     双曲线**，两支必须互为镜像、大小/形状/曲率/延伸程度完全一致。正确做法：在
     绘图区几何中心放原点 O（反比例函数禁止把原点塞到左下角），先用足够密且均匀
     的点（每支 8~12 个）画出第一支，第二支直接对第一支做**原点中心对称点反射
     (x,y)→(-x,-y)** 生成（禁止两支独立采样导致密度或长度不一）；每支平滑延伸、
     逼近坐标轴（渐近）但不接触，两支延伸程度对等。线性/抛物线因天然对称不受
     影响，本规则专门纠正双曲线等分式图象"两支不对称、一长一短、一胖一瘦"的失真。
   - 【双曲线必须平滑、无折角、无多余构造线】
     · 双曲线是光滑曲线，禁止用 2~4 段直线或带尖角的二次贝塞尔硬拼；必须用以下
       二者之一：① 每支至少 12~16 个均匀密集采样点连成的平滑折线（相邻点间距
       不得大到肉眼可见折角）；② 或 cubic Bézier（path 用 'C'）控制点合理，使
       曲线在定义域内二阶连续、逼近真实双曲线。
     · 采样策略：靠近渐近线（x≈0 或 y≈0）处加密，远离处可略疏；例如 k=6 时
       正支可取 x = 0.5,1,1.5,2,3,4,6,8,12（必要时插值加密），负支用中心反射
       (-x,-y) 生成，保证对称且光滑。
     · 曲线必须经过已标注点 A、B，且在这些点处切线方向自然、无折点；标签文字
       必须放在曲线分支外侧空白处，用淡色引线连接，禁止压在曲线上或与坐标轴刻度重叠。
     · 严禁在最终图象中保留红色/醒目的虚线"构造线"（如从画布边角到点的斜线）。
       若需说明反比例函数"矩形面积不变"等性质，应画成极淡的矩形框/阴影区域
       （opacity≤0.25），不能化成穿越画面的斜虚线。
     · 两支延伸程度、弯曲幅度、采样密度必须对等，QIII/QII 分支不能缩短或变形。
   - 二次函数：图象生长 + 顶点/对称轴/开口方向聚焦（本层不展开，详见计算层）。
   - 曲线一律平滑（path 贝塞尔或足够密的折线），禁止把双曲线画成角折线。

3. 函数交点与联立求解（"求解析式"类核心动作）：
   - 图象交点 = 两函数联立的方程组解；动画先用高亮圆点标两图象交点 A、B，
     再切到"代入点求参数"的代数动作：
       · 反比例函数：把交点坐标代入 y=k/x 求 k（如 A(2,4)→k=2×4=8）；
       · 一次函数：把两交点分别代入 y=mx+n 列二元一次方程组求 m、n。
   - 代数动作放临时层（方程组、消元过程逐行亮），求得的函数式用 persistent
     标注返回图象旁（与已画曲线呼应）。

4. 坐标几何运算（与 domain_geometry 共用口径，禁止两套坐标算法）：
   - 三角形面积优先用「坐标面积公式」S = ½|x₁y₂ − x₂y₁|（以 O 为原点时，
     S△AOB = ½|x_A·y_B − x_B·y_A|）；或「割补法」用矩形减去若干直角三角形，
     动画演示分割/补形过程并标注每块底高。
   - 线段 OA、OB 用高亮线段 + 虚线辅助（如向坐标轴作垂线的补形直角三角形）。

5. 图象不等式解集判读（"根据图象直接写解集"类）：
   - 把不等式转成"两图象上下关系"：k/x > mx+n ⇔ 双曲线在直线上方的 x 区间。
   - 动画在交点处切分区间，用阴影/填充高亮"上方"区域，逐区间读 x 范围；
     注意双曲线在 x=0 处断开 → 解集按 x<0 与 x>0 分段写（如 x<-1 或 0<x<2）。
   - 解集写法是复合题高频失分点，必须用图象高亮 + 文字双重确认。

6. 复合多小题分镜骨架（函数类常见三连：解析式 → 面积 → 不等式）：
   建坐标系并描已知交点 → 求各函数解析式（代入点）→ 求面积（坐标公式/割补）
   → 写不等式解集（图象上下关系）。一拍一个数学动作，坐标系全程复用，
   前问成果（k/m/n、交点 A/B）在后续拍作为已知高亮，不重画、不重算。
