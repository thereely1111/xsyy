# 本地开发环境快速开始

## 一键配置（推荐）

如果你已经配置好 `.env` 文件，可以直接运行：

```bash
cd backend

# 激活虚拟环境
# Windows: .venv\Scripts\activate
# Linux/Mac: source .venv/bin/activate

# 1. 创建数据库并初始化表结构
python setup_local_db.py

# 2. 迁移现有数据
python database/migrate.py

# 3. 验证配置
python verify_db_config.py
```

## 详细步骤

### 第一步：配置环境变量

1. 复制环境变量模板：
   ```bash
   cd backend
   cp env.example .env
   ```

2. 编辑 `.env` 文件，修改以下配置：
   - `DATABASE_URL`: 将 `password` 替换为你的 MySQL root 密码
   - `DEEPSEEK_API_KEY`: 填入你的 DeepSeek API 密钥
   - `ZENMUX_API_KEY`: 填入你的 ZenMux API 密钥

### 第二步：创建数据库和表结构

运行自动化脚本：
```bash
python setup_local_db.py
```

### 第三步：迁移数据

迁移现有的 JSON 文件数据到数据库：
```bash
python database/migrate.py
```

### 第四步：验证配置

检查数据库连接和数据迁移结果：
```bash
python verify_db_config.py
```

## 启动开发服务器

配置完成后，启动后端服务：

```bash
python -m uvicorn app:app --reload
```

服务将在 `http://localhost:8000` 启动。

### 测试 API

**Windows PowerShell:**
```powershell
# 方法 1: 使用测试脚本（推荐）
.\test_api.ps1

# 方法 2: 使用 Invoke-WebRequest
Invoke-WebRequest -Uri http://localhost:8000/api/health

# 方法 3: 使用 curl.exe（如果已安装 Git for Windows）
curl.exe http://localhost:8000/api/health

# 方法 4: 在浏览器中访问
# http://localhost:8000/api/health
```

**Linux/Mac:**
```bash
# 方法 1: 使用测试脚本（推荐）
bash test_api.sh

# 方法 2: 直接使用 curl
curl http://localhost:8000/api/health
```

**预期响应:**
```json

  "status": "ok",
  "message": "XSYY Backend is running",
  "timestamp": "2024-01-01T12:00:00"
}
```
