# 本地开发环境数据库配置指南

## 前置条件

- ✅ 已安装 MySQL（5.7+ 或 8.0+）
- ✅ MySQL 服务正在运行
- ✅ 已安装 Python 3.9+
- ✅ 已创建并激活虚拟环境
- ✅ 已安装项目依赖（`pip install -r requirements.txt`）

## 配置步骤

### 步骤 1：配置环境变量

1. 打开 `backend/.env` 文件
2. 修改 `DATABASE_URL` 中的密码：
   ```env
   DATABASE_URL=mysql+pymysql://root:你的MySQL密码@localhost:3306/xsyy?charset=utf8mb4
   ```
   例如，如果 MySQL root 密码是 `123456`，则：
   ```env
   DATABASE_URL=mysql+pymysql://root:123456@localhost:3306/xsyy?charset=utf8mb4
   ```

3. 确认 API 密钥已配置：
   - `DEEPSEEK_API_KEY` - DeepSeek API 密钥
   - `ZENMUX_API_KEY` - ZenMux API 密钥

### 步骤 2：创建数据库并初始化表结构

**方式一：使用自动化脚本（推荐）**

```bash
# 进入 backend 目录
cd backend

# 激活虚拟环境（如果还没有）
# Windows: .venv\Scripts\activate
# Linux/Mac: source .venv/bin/activate

# 运行自动化设置脚本（会自动创建数据库和表结构）
python setup_local_db.py
```

这个脚本会：
- 自动创建 `xsyy` 数据库（如果不存在）
- 初始化所有数据库表结构
- 验证数据库连接

**方式二：手动创建数据库**

```bash
# 连接到 MySQL
mysql -u root -p

# 在 MySQL 中执行以下 SQL
CREATE DATABASE IF NOT EXISTS xsyy CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
EXIT;
```

然后运行初始化脚本：

```bash
cd backend
python init_database.py
```

**方式三：使用 SQL 脚本**

```bash
# 在项目根目录执行
mysql -u root -p < backend/database/schema.sql
```

### 步骤 4：迁移现有数据

```bash
# 确保在 backend 目录下，虚拟环境已激活
python database/migrate.py
```

迁移脚本会：
- 迁移 `users/users.json` → `users` 表
- 迁移 `storage/*/metadata.json` → `teachings` 表
- 迁移评论、点赞、收藏数据 → 对应的关系表

### 步骤 5：验证配置

**使用验证脚本（推荐）：**

```bash
# 在 backend 目录下，虚拟环境已激活
python verify_db_config.py
```

这个脚本会检查：
- 数据库连接是否正常
- 所有表是否已创建
- 数据迁移结果统计

**手动验证：**

**测试数据库连接：**

## 常见问题

### 问题 1：数据库连接失败

**错误信息：** `(2003, "Can't connect to MySQL server")`

**解决方法：**
1. 确认 MySQL 服务正在运行
   - Windows: 在服务管理器中检查 MySQL 服务
   - Linux/Mac: `sudo systemctl status mysql` 或 `brew services list`
2. 确认端口 3306 未被占用
3. 检查 `.env` 文件中的 `DATABASE_URL` 配置是否正确

### 问题 2：Access denied for user

**错误信息：** `(1045, "Access denied for user 'root'@'localhost'")`

**解决方法：**
1. 确认 MySQL root 密码正确
2. 如果忘记密码，需要重置 MySQL root 密码
3. 检查 `.env` 文件中的密码是否正确（注意特殊字符需要 URL 编码）

### 问题 3：数据库不存在

**错误信息：** `(1049, "Unknown database 'xsyy'")`

**解决方法：**
1. 按照步骤 2 创建数据库
2. 或者修改 `DATABASE_URL` 使用已存在的数据库

### 问题 4：表已存在错误

**错误信息：** `Table 'users' already exists`

**解决方法：**
- 如果表已存在且需要重新创建，可以删除数据库后重新初始化：
  ```sql
  DROP DATABASE IF EXISTS xsyy;
  CREATE DATABASE xsyy CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
  ```
  然后重新运行 `python init_database.py`

### 问题 5：迁移数据时出现重复键错误

**错误信息：** `IntegrityError: Duplicate entry`

**解决方法：**
- 这是正常的，表示数据已经存在，迁移脚本会自动跳过
- 如果需要强制重新迁移，需要先清空相关表

## 下一步

配置完成后，你可以：

1. 启动后端服务进行开发
2. 使用数据库管理工具（如 MySQL Workbench、Navicat）查看和管理数据
3. 继续开发新功能

## 注意事项

- `.env` 文件包含敏感信息，不要提交到版本控制
- 开发环境可以使用简单的 JWT_SECRET，但生产环境必须使用强随机字符串
- 定期备份数据库：`mysqldump -u root -p xsyy > backup.sql`
