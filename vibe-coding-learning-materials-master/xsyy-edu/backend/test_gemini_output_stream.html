几何·平行四边形

Visual Geometry

“设 P 是平行四边形 ABCD 内部一点，且 ∠PBA=∠PDA，求证：∠PAB=∠PCB”

准备开始...

完整解法

  • 题目 已知 P 是平行四边形内一点，且 ∠PBA = ∠PDA。
  • 步骤一 将 △ABP 沿向量 AD 平移至右侧，得到 △DCQ。
    (此时 AB 与 DC 重合，P 移动到 Q)
  • 步骤二 由平移性质可知：∠DCQ = ∠ABP。
    结合已知条件，得 ∠DCQ = ∠PDA。
  • 步骤三 观察四边形 ADQP，PQ // AD。
    由平行线性质（内错角相等）：∠PDA = ∠DPQ。
  • 步骤四 结合步骤二与三：∠DCQ = ∠DPQ。
    因为这两个角对着同一条线段 DQ，所以点 P, D, C, Q 四点共圆。
  • 步骤五 在圆中，同弧所对圆周角相等：
    ∠QDC = ∠QPC。
    注意：∠QDC 其实就是平移前的 ∠PAB。
  • 结论 因为 PQ // BC (均平行于 AD)，内错角相等：
    ∠QPC = ∠PCB。
    综上所述：∠PAB = ∠PCB。证毕。
