# 内测码配置说明

## 概述
系统已启用内测码注册功能，用户必须输入正确的内测码才能完成注册。

## 配置方式

### 方式一：通过环境变量配置（推荐）

在 `.env` 文件中添加：

```env
BETA_CODE=你的内测码
```

例如：
```env
BETA_CODE=XSYY2025
```

### 方式二：使用默认值

如果没有设置环境变量，系统会使用默认内测码：`XSYY2025`

## 修改内测码

1. 修改 `.env` 文件中的 `BETA_CODE` 值
2. 重启后端服务使配置生效

## 注意事项

- 内测码区分大小写
- 建议定期更换内测码以提高安全性
- 内测码可以通过主页右上角"申请内测"功能获取（需要手动告知用户）

## 前端提示

前端注册界面会显示：
- 内测码输入框（必填）
- 红色提示文字："可在主页右上角申请内测处领取内测码"
