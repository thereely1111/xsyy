# 环境配置指南

## 📋 前置要求

- Python 3.8 或更高版本
- 已安装 pip（Python 包管理器）

## 🚀 完整配置步骤

### 步骤 1：创建 Python 虚拟环境

在项目根目录（`xsyy`）下执行：

```bash
# Windows
python -m venv .venv

# 激活虚拟环境
.venv\Scripts\activate
```

激活成功后，命令行提示符前会显示 `(.venv)`。

### 步骤 2：安装项目依赖

```bash
cd backend
pip install -r requirements.txt
```

### 步骤 3：配置环境变量

#### 3.1 创建 `.env` 文件

在 `backend` 目录下，复制示例文件：

```bash
# Windows
copy env.example .env
```

#### 3.2 编辑 `.env` 文件

打开 `backend/.env` 文件，填入你的 API 密钥：

```env
# DeepSeek API 密钥（必需）
# 获取地址：https://platform.deepseek.com/
DEEPSEEK_API_KEY=你的DeepSeek密钥

# ZenMux API 密钥（必需）
# 获取地址：https://zenmux.ai/
ZENMUX_API_KEY=你的ZenMux密钥

# 测试模式（可选）
# 设置为 1 时，使用预设回复，不调用真实 API
TEST_MODE=0
```

#### 3.3 获取 API 密钥

**DeepSeek API 密钥：**
1. 访问 https://platform.deepseek.com/
2. 注册/登录账号
3. 进入 API 密钥管理页面
4. 创建新的 API 密钥
5. 复制密钥到 `.env` 文件

**ZenMux API 密钥：**
1. 访问 https://zenmux.ai/
2. 注册/登录账号
3. 创建 API 密钥
4. 复制密钥到 `.env` 文件

### 步骤 4：验证配置

检查 `.env` 文件是否正确配置：

```bash
# 在 backend 目录下
type .env
```

确保：
- ✅ `DEEPSEEK_API_KEY` 不是 `your_deepseek_api_key_here`
- ✅ `ZENMUX_API_KEY` 不是 `your_zenmux_api_key_here`
- ✅ 密钥前后没有多余的空格

## 🎯 启动项目

### 方式一：生产模式（使用真实 API）

```bash
cd backend
.venv\Scripts\activate
uvicorn app:app --reload
```

或者使用启动脚本：

```bash
cd backend
.\start.bat
```

### 方式二：测试模式（无需 API 密钥）

适合快速测试前端功能，不调用真实 API：

```bash
cd backend
.\start-test.bat
```

或者在 `.env` 文件中设置：

```env
TEST_MODE=1
```

然后正常启动：

```bash
cd backend
.venv\Scripts\activate
uvicorn app:app --reload
```

## 🔧 常见问题

### 问题 1：找不到 `.venv` 文件夹

**解决**：在项目根目录执行 `python -m venv .venv`

### 问题 2：`pip install` 失败

**解决**：
- 检查网络连接
- 尝试使用国内镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

### 问题 3：提示 "缺少环境变量 DEEPSEEK_API_KEY"

**解决**：
- 确保 `.env` 文件在 `backend` 目录下
- 检查 `.env` 文件中的密钥是否正确
- 确保密钥前后没有引号或空格

### 问题 4：虚拟环境激活失败

**解决**：
- Windows：使用 `.venv\Scripts\activate.bat`
- 如果还是失败，尝试：`.venv\Scripts\python.exe -m pip install -r requirements.txt`

## 📝 注意事项

1. **`.env` 文件不要提交到 Git**：已添加到 `.gitignore`
2. **API 密钥安全**：不要分享你的 `.env` 文件
3. **测试模式**：适合开发测试，返回的是预设模板，不是真实生成的内容
4. **生产模式**：需要有效的 API 密钥，会产生 API 调用费用
