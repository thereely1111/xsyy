# XSYY（象数演易）项目介绍（2026.04 迭代版）

## 一、项目定位

XSYY（象数演易）是一个面向数学教育场景的 AI 教学应用生成平台。

平台核心目标是：
- 把学生/教师输入的题目（文本、图片、文档等）自动转化为可交互的教学 HTML；
- 通过分类、标签、推荐与专题沉淀形成可复用内容资产；
- 通过用户系统、管理后台、监控和部署体系支撑线上稳定运行。

当前版本已从“单次生成工具”升级为“教学内容生产 + 管理 + 分享 + 助教问答”的完整闭环系统。

---

## 二、已落地的核心能力

### 1. AI 题目分析与教学内容生成
- 两阶段流水线：先分析题目，再生成教学应用。
- 自动识别数学题目并提取关键信息（标题、标签、题干结构等）。
- 生成单文件 HTML 教学内容，便于快速预览、传播和存档。
- 支持任务异步执行，前端可实时查看任务状态和进度。

### 2. 多输入形态与上传体验
- 支持文本输入和文件上传。
- 支持拍照上传（浏览器摄像头能力）。
- 上传过程提供进度反馈与任务队列展示。
- 任务结果包含教学 HTML、预览图与结构化元数据。

### 3. 用户系统与身份认证
- 用户注册/登录：账号密码、手机号验证码双链路。
- JWT 身份认证与个人资料管理。
- 支持找回密码、修改密码、绑定手机号/邮箱。
- 支持按用户维度的每日调用额度控制。

### 4. 内容互动与个人资产沉淀
- 教学内容列表、筛选、搜索。
- 点赞、评论、收藏。
- 浏览历史记录与个人中心管理。
- 教学内容下载与删除。

### 5. 专题（Topic）与分享
- 用户可创建、编辑、删除专题。
- 支持将教学内容加入/移出专题。
- 支持专题批量导入内容。
- 支持专题生成分享链接（含令牌与过期策略），并提供公开分享页。

### 6. 语义相似推荐
- 对教学题目进行向量化并写入向量数据库。
- 基于语义相似度返回推荐内容。
- 在生成失败或删除时执行向量数据清理，保障一致性。

### 7. AI 助教问答
- 提供 AI 助教摘要初始化与对话接口。
- 维护会话摘要缓存与问答记录。
- 支持基于问题相似度的历史问答复用，降低重复调用成本。

### 8. 管理后台
- 管理员白名单认证与权限隔离。
- 教学内容管理：查看、检索、详情、删除。
- 用户管理：用户信息查看与调用额度配置。
- 系统配置管理：内测码、默认额度、匿名额度等。
- 统计看板：用户、内容、互动数据与系统指标汇总。

### 9. 监控与可观测性
- 暴露 Prometheus 指标。
- 覆盖 HTTP 请求、任务执行、数据库连接池、缓存命中等关键指标。
- 提供健康检查与指标摘要接口，便于运维巡检与告警接入。

### 10. 性能优化机制
- 教学 HTML 内存缓存 + gzip 压缩（含命中统计）。
- 同题任务复用与缓存映射，减少重复生成。
- 前端任务队列轮询优化，降低无效请求。
- 生成链路支持异常兜底与重试策略。

## 三、系统架构概览

### 1. 总体架构
- 前后端分离架构。
- 后端提供 RESTful API 与静态资源能力。
- 前端以原生 HTML/CSS/JavaScript 构建多页面应用。

### 2. 后端技术栈
- Web 框架：FastAPI + Uvicorn
- ORM：SQLAlchemy
- 鉴权：PyJWT
- 数据库：MySQL（关系数据）+ ChromaDB（向量数据）
- AI 编排：LangChain
- 模型调用：DeepSeek、Gemini（含网关兼容配置）
- 异步与网络：asyncio、aiohttp
- 文件与图像：python-docx、pypdf、Pillow
- 监控：prometheus-client、psutil

### 3. 前端技术栈
- 原生 HTML/CSS/JavaScript
- 响应式布局与新中式视觉风格
- Fetch/XHR 异步交互
- MathJax 数学公式渲染
- 浏览器摄像头拍照上传
- 管理后台独立页面与 JS API 封装

### 4. 部署与运维
- Nginx 反向代理与静态资源托管
- systemd 进程管理
- 脚本化部署（dev/prod/rollback/migrate/version）
- 支持云服务器（腾讯云 OpenCloudOS）部署流程

## 四、核心业务流程

### 1. 题目生成主流程
1. 用户提交题目（文本或文件）。
2. 后端创建任务并入队异步处理。
3. AI 分析与 HTML 生成流水线执行。
4. 持久化任务结果（题目信息、标签、HTML、预览图）。
5. 写入向量库用于后续相似推荐。
6. 前端轮询任务状态并展示结果。

### 2. 专题分享流程
1. 用户在个人中心管理专题与内容。
2. 创建分享链接并设置时效。
3. 访客通过分享令牌访问公开专题页。
4. 系统校验令牌状态与过期时间后返回内容。

### 3. AI 助教流程
1. 页面内容生成会话摘要缓存。
2. 用户发起追问。
3. 系统优先尝试相似问题命中缓存答案。
4. 未命中时调用模型生成回复并回写问答记录。

## 五、数据模型（当前版本）

核心表/实体包括：
- users（用户）
- verification_codes（验证码）
- teachings（教学内容）
- comments（评论）
- comment_likes（评论点赞）
- teaching_likes（内容点赞）
- favorites（收藏）
- user_view_history（浏览历史）
- topics（专题与分享）
- ai_teaching_session（助教会话摘要缓存）
- ai_teaching_qa（助教问答记录）

数据分层策略：
- 结构化业务数据在 MySQL；
- 向量嵌入在 ChromaDB；
- 生成产物文件在本地存储目录。
